# Changelog

All notable user-visible changes will be documented in this file.

## [Unreleased]

### Added

- Repository, licensing, contribution, and CI baseline.
- Dependency-free canonical event and local wire protocols with runtime validation.
- Crash-safe append-only JSONL sessions, tree reconstruction, redaction, and deterministic replay.
- Provider foundation with credentials, thinking levels, tool dialects, a deterministic fake, and the first Azure OpenAI adapter.
- Minimal agent loop with shell, read, and edit tools, stable prompts, cancellation, and operation ownership.
- Authoritative Unix-socket daemon and fail-closed Bubblewrap sandbox.
- Interactive TUI with Unicode-aware multiline editing, responsive differential rendering, framed usage and repository metrics, bordered prompts, compact tool rendering, adaptive diffs, the custom Gruvbox theme, model/thinking/theme selectors, queued prompts, and detached-daemon resume.
- Agent Skills discovery, validation, progressive instruction loading, and protected resource access.
- MCP 2025-11-25 client support for stdio and Streamable HTTP, OAuth, tools, resources, prompts, completions, roots, sampling, elicitation, tasks, progress, cancellation, and logging.
